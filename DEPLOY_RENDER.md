# Деплой на Render.com

## Вариант 1: Автоматический через render.yaml (Blueprint)

В репозитории уже есть файл `render.yaml`. Render автоматически подхватит его при подключении репозитория.

1. Зайдите на https://dashboard.render.com
2. Нажмите **New** → **Blueprint**
3. Подключите GitHub-репозиторий с проектом
4. Render обнаружит `render.yaml` и предложит создать сервис
5. Перед деплоем укажите значение `ANTHROPIC_API_KEY` в секретных переменных
6. Нажмите **Apply**

## Вариант 2: Ручная настройка Web Service

### Шаг 1. Создание сервиса

1. Зайдите на https://dashboard.render.com
2. Нажмите **New** → **Web Service**
3. Подключите GitHub-репозиторий с проектом
4. Заполните настройки:

| Параметр | Значение |
|----------|---------|
| **Name** | `smeta-parser` |
| **Runtime** | Node |
| **Build Command** | `npm run render:build` |
| **Start Command** | `npm start` |
| **Plan** | Standard (или выше) |

### Шаг 2. Переменные окружения

В разделе **Environment** → **Environment Variables** добавьте:

| Переменная | Значение | Обязательно |
|-----------|---------|-------------|
| `NODE_ENV` | `production` | Да |
| `ANTHROPIC_API_KEY` | `sk-ant-api03-...` (ваш ключ Anthropic) | Да (для AI-декомпозиции) |
| `CLAUDE_MODEL` | `claude-sonnet-4-20250514` | Нет (есть значение по умолчанию) |
| `UPLOAD_DIR` | `/app/uploads` | Нет (по умолчанию `./uploads`) |
| `MAX_FILE_SIZE` | `50mb` | Нет (по умолчанию 50mb) |

> Ключ `ANTHROPIC_API_KEY` получите на https://console.anthropic.com/settings/keys
> Без него AI-декомпозиция расценок будет недоступна — расценки будут
> добавляться в ВОР как есть (одна расценка = одна строка).

### Шаг 3. Подключение диска (опционально, но рекомендуется)

Загруженные файлы и сгенерированные XLSX/DOCX хранятся в папке `uploads/`.
По умолчанию на Render файловая система **ephemeral** — файлы удаляются при
каждом деплое. Чтобы файлы сохранялись:

1. В настройках сервиса перейдите в раздел **Disks**
2. Нажмите **Add Disk**
3. Заполните:
   - **Name:** `uploads`
   - **Mount Path:** `/app/uploads`
   - **Size:** 1 GB (увеличьте при необходимости)
4. Убедитесь, что переменная `UPLOAD_DIR` = `/app/uploads`

### Шаг 4. Деплой

1. Нажмите **Create Web Service**
2. Дождитесь завершения билда (обычно 2-3 минуты)
3. Откройте URL сервиса — вы увидите главную страницу загрузки

## Что происходит при деплое

Команда `npm run render:build` последовательно выполняет:

```
1. npm install              — установка зависимостей бэкенда
2. npm run client:build     — установка зависимостей фронтенда + сборка React (Vite)
3. npm run build            — компиляция TypeScript бэкенда
```

Результат:
```
/app/
├── dist/              ← скомпилированный бэкенд (server.js, API)
├── client/dist/       ← собранный фронтенд (index.html, assets/)
├── node_modules/      ← зависимости
└── uploads/           ← загруженные/сгенерированные файлы
```

Express-сервер раздаёт фронтенд как статику и проксирует API-запросы.

## Проверка работоспособности

После деплоя проверьте:

```bash
# Health check
curl https://ваш-сервис.onrender.com/api/health

# Ожидаемый ответ:
# {"status":"ok","version":"1.0.0","uptime":...}
```

Откройте в браузере URL сервиса — должна отобразиться страница загрузки файлов.

## Ограничения бесплатного плана Render

| Ограничение | Free | Standard |
|-------------|------|----------|
| Время работы | Засыпает через 15 мин неактивности | Работает постоянно |
| Диск | Не поддерживается | До 256 GB |
| RAM | 512 MB | 2 GB |
| CPU | Shared | Dedicated |

Для production рекомендуется план **Standard** ($7/мес) или выше — для
поддержки диска и стабильной работы.

## Обновление

При каждом `git push` в подключённую ветку Render автоматически запустит
новый деплой. Для ручного деплоя нажмите **Manual Deploy** → **Deploy latest commit**
в дашборде Render.

## Troubleshooting

| Проблема | Решение |
|----------|---------|
| Билд падает на `npm run client:build` | Проверьте, что `client/package.json` существует и содержит скрипт `build` |
| 503 после деплоя | Проверьте логи: **Logs** в дашборде. Обычно — ошибка в переменных окружения |
| Файлы пропадают после деплоя | Подключите Render Disk (шаг 3) |
| AI-декомпозиция не работает | Проверьте `ANTHROPIC_API_KEY` в переменных окружения |
| Фронтенд не загружается | Убедитесь, что `client/dist/` создаётся при билде (проверьте логи билда) |
